# Image Uploads

Upload your tourism photos here using the GitHub interface:

1. Click "Add file" → "Upload files"
2. Select your images
3. Use these exact filenames:
   - hero.jpg (main banner image)
   - fishing.jpg
   - wildcoast.jpg
   - holeinthewall.jpg
   - accommodation.jpg
   - horseriding.jpg
   - sunset.jpg

All images will automatically appear on your website!
